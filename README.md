Nombre del Proyecto: InventiAPP

Descripción: InventiAPP es una aplicación móvil diseñada para gestionar stock de una organización que gestiona productos tecnológicos y de telecomunicaciones.
Está pensada para consultar existencias, registrar movimientos y salidas. Además posee funcionalidad de escaneo de código QR y envío de notificaciones.

Pasos: 
Abrir la app en el menú de aplicaciones. posee nombre inventiapp.

Ingresar con "admin@inventiapp.cl", "bodega@inventiapp.cl" o "ventas@inventiapp.cl".

clave: cualquier string que posea 4 carácteres o más.
